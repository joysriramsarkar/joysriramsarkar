## 👋 পরিচিতি | About Me

আমি **জয়শ্রীরাম সরকার** — একজন ডেভেলপার, যে বাংলা ভাষার জন্য সফটওয়্যার বানায়।
কীবোর্ড থেকে সার্চ ইঞ্জিন, POS অ্যাপ থেকে প্রোগ্রামিং ল্যাঙ্গুয়েজ আর অপারেটিং সিস্টেম, আমার লক্ষ্য একটাই: **বাংলাভাষী মানুষ যেন প্রযুক্তিতে কারও পেছনে না থাকে।**

> *I build web and mobile software with Bengali as a first-class citizen, from a keyboard and a search engine to a programming language and a mobile OS.*

- 🔭 **এখন যা নিয়ে কাজ করছি:** `NilLang` ও তার এমুলেটর, `Onuron OS`, আর **লক্ষ্মণ ভাণ্ডার** POS অ্যাপকে স্থিতিশীল করা
- 🌱 **এখন যা শিখছি:** ল্যাঙ্গুয়েজ রানটাইম ডিজাইন, টেক্সট শেপিং, মোবাইল OS-এর HAL
- 🎯 **স্বপ্ন:** বাংলা ভাষাকে সারা বিশ্বে জনপ্রিয় করা, আর বাংলার নিজস্ব ওপেন-সোর্স টেক ইকোসিস্টেম গড়ে তোলা
- 💬 **আমাকে জিজ্ঞেস করতে পারেন:** বাংলা কীবোর্ড/IME, বাংলা OCR, Next.js + PostgreSQL POS আর্কিটেকচার, অফলাইন-ফার্স্ট অ্যাপ
- 🌐 **ভাষা:** বাংলা (মাতৃভাষা), English
